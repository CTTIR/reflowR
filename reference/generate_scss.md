# Generate Theme SCSS from a Color Scheme

Creates a Quarto-compatible SCSS file with custom properties.

## Usage

``` r
generate_scss(scheme, output_path)
```

## Arguments

- scheme:

  A scheme list from
  [`reflow_scheme()`](https://rabanheller.github.io/reflowR/reference/reflow_scheme.md).

- output_path:

  Character. File path for the output SCSS file.

## Value

Invisibly returns the output path.
