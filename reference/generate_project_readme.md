# Generate Project README

Creates a README.md in the project root.

## Usage

``` r
generate_project_readme(project_dir, name, author, scheme, preset)
```

## Arguments

- project_dir:

  Character. Path to the project root.

- name:

  Character. Project name.

- author:

  Character. Author name.

- scheme:

  A scheme list.

- preset:

  A preset list.

## Value

Invisibly returns the output file path.
