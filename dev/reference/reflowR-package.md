# reflowR: Themed Extensions for 'workflowr' Research Workflows

Extends the 'workflowr' package with themed colour schemes, structured
analysis pipeline templates and utility scripts for reproducible
research. Wraps wflow_start() from 'workflowr' and adds the nine topic
families of the Computational Trauma and Tissue Injury Research (CTTIR)
v5 design language as site schemes (Okabe-Ito accents, light and dark
surfaces, Inter and JetBrains Mono typography from shared design
tokens), three depth presets for the R Markdown pipeline (minimal,
standard, extended), CSS/SCSS theming, SVG family icons, 'ggplot2' theme
functions and a 'Quarto' report template. All generated projects remain
fully compatible with standard 'workflowr' commands. Further interfaces
run file-producing analysis steps and imaging workflows of installed
package functions as fingerprinted, resumable pipelines with verified
receipts, and scaffold and validate strict project profiles.
