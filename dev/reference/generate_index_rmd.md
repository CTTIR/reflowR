# Generate index.Rmd

Generate index.Rmd

## Usage

``` r
generate_index_rmd(project_dir, name, author, email, scheme, preset)
```

## Arguments

- project_dir:

  Character. Path to project root.

- name:

  Character. Project name.

- author:

  Character. Author name.

- email:

  Character or NULL. Author email.

- scheme:

  A scheme list.

- preset:

  A preset list.

## Value

Invisibly returns the output file path.
